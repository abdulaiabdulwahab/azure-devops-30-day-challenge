One of the biggest lessons from today was learning to troubleshoot from the inside out.

Instead of immediately assuming the cloud infrastructure is broken, I’m learning to work through the layers systematically:

**Application → Service → Operating System → Network → Security → Azure Resource Configuration**

For example, if an application is inaccessible:

➡️ Is the VM running?
➡️ Can I SSH into it?
➡️ Is the application service running?
➡️ Does `curl localhost` work?
➡️ Is the correct port listening?
➡️ Does the NSG allow the traffic?
➡️ Is the public IP or DNS configuration correct?

That troubleshooting mindset is something I want to continue developing throughout this challenge.
